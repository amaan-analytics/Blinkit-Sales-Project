# 🛒 Blinkit Sales Dashboard | Power BI

This interactive Power BI dashboard provides a comprehensive analysis of **Blinkit’s sales performance**.  
It highlights key insights into total sales, outlet performance, item types, and customer behavior — helping identify top-performing outlets and categories across India.

## 💡 Key Insights
- **Total Sales:** $1.20M  
- **Average Sales:** $141  
- **Number of Items:** 9K  
- **Average Rating:** 3.92  
- **Top Outlet:** Tier 3 Outlets (contributing ~39% of total sales)  
- **Highest Rated Outlet Type:** Grocery Store (Avg. Rating 3.93)  

---

## ⚙️ Dashboard Features
- Interactive filters for **Outlet Size**, **Location Type**, and **Item Type**  
- Visuals include bar charts, donut charts, and KPI cards  
- Clear visual hierarchy for smooth analysis flow  
- Consistent yellow-green Blinkit-themed color scheme  
- Optimized for both insights and aesthetics
